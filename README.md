## 📖 About The Project

Developed specifically for the **Sıla İhsan Derneği** (Sıla İhsan Association), this web project is designed according to modern web standards to globally promote their humanitarian aid, orphan sponsorship, health, education, and emergency support activities. It stands out with a fluid user experience, advanced animations, and comprehensive multi-language support.

## ✨ Key Features

- 🌐 **Comprehensive Multi-Language Support:** Seamless experience in English, Turkish, and Arabic (RTL).
- 🎨 **Modern & Dynamic UI:** Smooth scrolling and interactive animations built with GSAP, ScrollTrigger, Lenis, and Framer Motion.
- ⚡ **High Performance:** Ultra-fast page load times powered by Vite and React 18 architecture.
- 📱 **Fully Responsive Design:** Flawless appearance across all devices (Mobile, Tablet, Desktop).
- 🔍 **Advanced SEO Infrastructure:** Search Engine Optimization, Open Graph, Twitter Card, sitemap, and robots.txt integration.
- 🌓 **Theme Support:** Dynamic color and theme management.

## 🛠️ Technologies Used

- **Frontend Core:** React 18, Vite
- **Animation & Scrolling:** GSAP, Framer Motion, Lenis (Smooth Scroll)
- **Internationalization (i18n):** react-i18next
- **Styling & Design:** Sass (SCSS), CSS Modules, Classnames
- **Deployment:** Ready for Vercel / Netlify

## 📂 Project Structure

```text
src/
├── components/      # Reusable, modular UI components
├── context/         # Global state and theme management files
├── data/            # Static content and mock data
├── hooks/           # Custom React hooks
├── locales/         # Language translation files (EN, TR, AR)
└── pages/           # Home page and other section components
```

## 🚀 Getting Started

Follow these steps to run the project locally:

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start the Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```

4. **Preview the Production Build:**
   ```bash
   npm run preview
   ```

## 🌍 Deployment

This project generates static Vite output and can be easily deployed on popular hosting services.

**Recommended Vercel Settings:**
- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Install Command:** `npm install`
